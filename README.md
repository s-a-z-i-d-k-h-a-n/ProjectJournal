# ProjectJournal

A personal developer portfolio built with React and Vite. It introduces a CSE student, highlights current skills and a featured Library Management System project, and includes a small interactive counter.

## Features

- About, skills, projects, and contact sections with in-page navigation
- Interactive counter with increment and reset buttons
- Responsive layout with a dark gradient design

## Getting Started

Install the dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Open the local URL printed in the terminal to view the site.

## Available Scripts

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
